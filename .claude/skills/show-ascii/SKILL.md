# Show-ASCII

Goal: Make the most important insight visually undeniable through terminal visuals in chat.
Target: Concept, system, flow, or data the user points at; infer from full chat context.
Scope: Chat output only; full terminal character range — Unicode box-drawing, block elements, emoji, ANSI color — rendered in JetBrains Mono; no files.
Output: Walk through the Process below in chat, showing each step's work, then render.

## Process
1. Info Goal: List, in order, the most important information the user needs to understand (inverted pyramid).
2. Visual Technique: Choose the visual technique that maximizes the 1st Info Goal.
3. Visual Implementation: Describe how to maximize the visual impact of the 1st Info Goal within the chosen technique (data-ink ratio, Tufte).
4. Implement: Render; the agent decides how many visuals the material needs, each earning its place against an Info Goal.

Requirements:
1. Visually, optimally vertically and horizontally aligned
